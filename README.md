# jam-qa-next

QA fixture for Jam (fictional brand "Ferrowind"). Next.js 15 app router, marketing pages in the
`app/(marketing)` route group, markdown posts in `content/posts/`. Static export (`output: 'export'`)
deployed to GitHub Pages by `.github/workflows/deploy.yml` on push to `main`.
Live: https://wespreadjam.github.io/jam-qa-next/
